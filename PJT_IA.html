Supervised Image Classification with CNN

A comparative study of Convolutional Neural Networks, Transfer Learning, and Ensemble Methods applied to MNIST and Fashion MNIST datasets.

1. CNN Architecture & MNIST Results

The objective of this project was to create a model capable of recognizing handwritten digits and clothing objects. We developed a Convolutional Neural Network (CNN) structured with alternating Convolution layers (to extract features), Pooling layers (to reduce dimensionality), and final Dense layers for classification.

The model was trained on the MNIST dataset (70,000 images of digits 0-9). The initial CNN model achieved a high performance with an accuracy of 98%. The confusion matrix (right) highlights the model's precision, with very few misclassifications between digits.

2. Transfer Learning: KNN vs. Dense Layers

We extended the study to the more complex Fashion MNIST dataset (10 classes of clothing). We explored a Transfer Learning approach by using the trained CNN primarily for feature extraction.

We compared two classification methods using the extracted features:
• Method 1 (KNN): A K-Nearest Neighbors algorithm ($k=10$).
• Method 2 (Dense): The standard final dense layer of the neural network.

The initial Fashion MNIST model achieved an accuracy of 89%. As seen in the confusion matrix, distinguishing between similar items like "Shirt," "T-shirt/top," and "Coat" proved more challenging than digit recognition.

3. Ensemble Methods & Optimization

To improve robustness and accuracy, we implemented an Ensemble Method combining three distinct models:

  • Model 1: Initial Network.
  • Model 2: Sigmoid activation ($\sigma(x)=\frac{1}{1+e^{-x}}$) + Dropout layer.
  • Model 3: ReLU activation ($f(x)=\max(0,x)$) + Layer removal + Dropout.

We aggregated predictions using a tiered logic: 1) Unanimous agreement, 2) Majority vote (2/3), 3) Divergence handling. This approach smoothed the learning curves (see graph) and improved the final global accuracy to roughly 89.8%.
